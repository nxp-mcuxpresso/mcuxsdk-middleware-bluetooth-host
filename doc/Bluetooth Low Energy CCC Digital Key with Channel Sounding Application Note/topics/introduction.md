# Introduction

NXP hardware platforms support the Bluetooth Low Energy applications implementing the Car Connectivity Consortium \(CCC\) Digital Key with channel sounding \(CS\) functionality. This document provides an overview of the deployment and operation of these applications, which also support the Bluetooth LE Channel Sounding localization functionality. This document is also a user guide for the sample applications included in the SDK release package.

## Audience

The document also provides an overview of the procedure and steps to deploy and operate the Bluetooth Low Energy applications \(enabling CCC Digital Key with CS\). The NXP hardware platforms supporting these applications are the KW47-EVK, KW47-LOC and FRDM-KW43 boards.

This document is a useful reference for firmware and system developers who create CCC Digital Key-enabled products. The document also provides a high-level description of CCC Digital Key application scenarios that can be deployed on NXP development boards.

# Demo functionality overview

The two demo applications provided showcase the following Digital Key R3 features:

-   Owner Pairing between a Device and a Car Anchor
-   Passive Entry
-   Synchronizing bonding data between Car Anchors
-   Connection between a Car Anchor and a non-CCC key fob

The two demo applications showcase the following localization features:

-   Distance measurement through Channel Sounding
-   Distance measurement data transfer through L2CAP
-   Ranging algorithms
    -   Complex-domain Distance Estimation \(CDE\)
    -   Rapid Accurate Distance Estimator \(RADE\)

The demo applications showcase the NXP proprietary Connection Handover and Anchor Monitoring features, and the A2B feature \(secured synchronization of bonding data\).

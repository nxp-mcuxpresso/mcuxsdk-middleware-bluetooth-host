# User interface

After flashing, both devices are in idle mode. To start scanning on the TPMS Monitor, press the **SCANSW** button. To start advertising on the TPMS Sensor, press either the **CONNADVSW** or **NCONNADVSW** buttons. When in GAP Limited Discovery Mode or scanning mode, **CONNLED** is flashing on either device. When the devices connect, **CONNLED** turns solid. To disconnect the TPMS Monitor, hold the **SCANSW** button pressed for 2-3 seconds.

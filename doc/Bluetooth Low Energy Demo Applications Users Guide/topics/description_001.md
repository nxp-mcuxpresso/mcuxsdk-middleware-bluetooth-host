# Description

The Bluetooth LE FSCI Black Box application exposes the full Bluetooth LE Host Stack over a serial interface through the FSCI (Framework Serial Communication Interface) protocol. An external host sends FSCI commands and receives FSCI events on this serial link to control all Bluetooth LE operations (GAP, GATT, GATTDB, L2CAP, NVM).

For FSCI protocol details, command/event definitions, XML packet descriptors, and Python scripting examples, see the [Bluetooth Low Energy Host Stack FSCI Application Programming](../../Bluetooth%20Low%20Energy%20Host%20Stack%20FSCI%20Application%20Programming/Bluetooth%20Low%20Energy%20Host%20Stack%20FSCI%20Application%20Programming.md) guide.

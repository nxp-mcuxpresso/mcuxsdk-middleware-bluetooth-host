# Supported platforms

The following platforms support Extended Advertising Peripheral and Central applications:

-   KW45B41Z-EVK
-   K32W148-EVK
-   FRDM-MCXW71
-   MCX-W71-EVK
-   KW47-EVK
-   FRDM-MCXW72
-   MCX-W72-EVK

Deep-sleep mode is used by default.

# Hardware requirements

The NXP Bluetooth LE demo applications are designed to run on any of these supported platforms:

-   KW45B41Z-EVK
-   K32W148-EVK
-   FRDM-MCXW71
-   MCX-W71-EVK
-   KW47-EVK
-   FRDM-MCXW72
-   MCX-W72-EVK
-   FRDM-MCXW23
-   MCXW23-EVK

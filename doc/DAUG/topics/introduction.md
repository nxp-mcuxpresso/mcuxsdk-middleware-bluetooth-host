# Introduction

This document describes the Bluetooth Low Energy host stack enablement for NXP development platforms. The document is organized as follows:

-   [Bluetooth Low Energy applications](bluetooth_low_energy.md) lists the demo applications that can be located in the Software Development Kit \(SDK\).

-   [Hardware configurations](hardware_configurations.md) describes the hardware and toolchain requirements.

-   [Building and running a Bluetooth LE example application](building_and_running_a_bluetooth_le_example_applic.md) describes the general requirements for using and testing a Bluetooth Application on a compatible device.

-   [Bluetooth LE stack and demo applications](bluetooth_le_stack_and_demo_applications.md) describes the steps and instructions for using the demo applications on your device. It also presents the profiles and services implemented and how to interact with them.

-   [References](reference_documentation.md) lists the additional documents that can be referred for more information.
-   [Acronyms](Acronyms.md) lists the acronyms used in this document.

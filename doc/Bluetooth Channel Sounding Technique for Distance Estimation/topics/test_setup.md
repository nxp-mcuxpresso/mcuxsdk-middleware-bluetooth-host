# Test setup description

The basic test setup description is based on information provided in the following complementary application notes:
-   Channel Sounding Wireless Ranging Demo Application
-   KW47 Wireless Ranging Performance Measurement. The individual test setup is not part of this document.

The Channel Sounding Wireless Ranging Demo Application document contains simple out-of-box test setup description with all the important settings. The KW47 Wireless Ranging Performance Measurement is a validation report which uses more complex HW test setup to achieve precise and statistically evaluated results.

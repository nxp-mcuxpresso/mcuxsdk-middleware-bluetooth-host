# Localization Reader

The Localization Reader application implements the Ranging Service \(RAS\) client side. This application runs the localization algorithm using the local and remote measurement data received through RAS. Both the GAP central and peripheral roles, as well as the Channel Sounding initiator and reflector roles are supported and can be configured at compile time. In the default configuration, the application is a GAP central and Channel Sounding initiator.

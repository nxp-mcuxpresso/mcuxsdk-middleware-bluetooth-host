# Localization Reader

The Localization Reader application is a Bluetooth Low Energy peripheral that implements the Ranging Service \(RAS\) client side. This application runs the localization algorithm using the local and remote measurement data received through RAS. Both the initiator and reflector Channel Sounding roles are supported and can be configured at compile time. In the default configuration, the reflector role is used.

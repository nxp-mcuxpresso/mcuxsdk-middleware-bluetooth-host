# Localization User Device

The Localization User Device implements the RAS server side. Both the GAP central and peripheral roles, as well as the Channel Sounding initiator and reflector roles are supported and can be configured at compile time. In the default configuration, the application is a GAP peripheral and Channel Sounding reflector. The Localization User Device does not run the localization algorithms.

# Localization User Device

The Localization User Device acts as a Bluetooth Low Energy central that implements the RAS server side. Both the initiator and reflector Channel Sounding roles are supported and can be configured at compile time. In the default configuration, the initiator role is used. The RAS server stores local measurement data and sends it to the RAS client. The Localization User Device does not run the localization algorithms.

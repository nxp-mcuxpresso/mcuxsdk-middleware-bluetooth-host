# Hardware and software requirements

For information on hardware setup and how to build and flash an application using the toolchain of your choice, see the *Getting Started Guide* for your selected board.

CS wireless ranging demo application is designed to run on KW47-EVK, KW47-LOC, MCX-W72-EVK, MCXW72-LOC, FRDM-MCXW72 and FRDM-KW43 platforms, referred to as "board" in the rest of this document.

# Prerequisites

Channel Sounding functionality can be integrated into an application that fulfills the following requirements:

-   Supported platforms: KW47-EVK, KW47-LOC, FRDM-MCXW72, MCX-W72-EVK, and MCX-W72-LOC.
-   Bluetooth Low Energy application that uses the `lib_ble_OPT_host_cm33_iar/gcc.a` Host library and the `lib_channel_sounding_iar/gcc.a` library.
